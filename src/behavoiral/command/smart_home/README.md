Mavzu: Aqlli uyni boshqarish tizimi (Smart Home)

Aqlli uy qurilmalarini boshqarish tizimini yarating. Foydalanuvchi maxsus pult yordamida qurilmalarni boshqarishi kerak.

Quyidagilarni amalga oshiring:

Command — execute() metodiga ega interfeys.

Light — turnOn() va turnOff() metodlariga ega chiroq qurilmasi.

AirConditioner — turnOn() va turnOff() metodlariga ega konditsioner.

LightOnCommand — chiroqni yoqish komandasi.

LightOffCommand — chiroqni o‘chirish komandasi.

AirConditionerOnCommand — konditsionerni yoqish komandasi.

RemoteControl — komandalarni qabul qiladigan va bajaradigan boshqaruv pulti.

Main — dasturning ishlashini namoyish qilish.

Shartlar:

Foydalanuvchi chiroqni yoqishi va o‘chirishi kerak.

Foydalanuvchi konditsionerni yoqishi va o‘chirishi kerak.

Har bir amal alohida komanda bo‘lishi kerak.

Pult qurilmalarni to‘g‘ridan-to‘g‘ri boshqarmasligi, balki Command interfeysi orqali ishlashi kerak.
